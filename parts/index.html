#

Pick a topic

A name becomes an address: hash the script OP_RETURN <name>, wrap it as P2WSH. Unspendable by consensus, indexed by every explorer.
₿

Burn to it

Send sats to the topic address and add an OP_RETURN with your take, 80 bytes max. Sats are the weight. A burn with no take counts as abstain.
Σ

Anyone can count

List the address's transactions, read each OP_RETURN, sum sats per take after trimming, lowercasing and stripping punctuation. This page does it in your browser.
